# まきむらのポートフォリオ
ちょっとした3DCGのギミックがあるWebサイトです。\
自分のことや、これまでの成果物を紹介しています。\
[makimura.me](https://www.makimura.me)

盛り込みたい要素がたくさんあるので、これからも随時更新していきます。

## 記事や演奏を追加する

```bash
pnpm new:post
```

対話に答えると、frontmatterを埋めた `.mdx` と画像の置き場所ができます。
できた記事は下書き（`published: false`）なので、書き終えたら `true` にすると公開されます。

| | 記事 | 画像・動画 |
| --- | --- | --- |
| ブログ | `src/contents/blog` | `public/blog/<記事の名前>` |
| 制作物 | `src/contents/works` | `public/works/thumbnail`、`public/works/products` |

どちらも `category` で一覧を絞り込めます。

- ブログ … `tech`（テック）・`dev`（開発日記）・`life`（生活）
- 制作物 … `software`（ソフトウェア）・`cg`（CG）・`music`（音楽）

ブログの一覧はZennの記事と混ざって新しい順に並びます。Zennの記事は `tech` として扱われます。

制作物の一覧は、カテゴリごとの既定の並び順（ソフトウェア・CG → 音楽の順）→ 同じ並びの中では新しい順、で並びます。
力を入れた作品をカテゴリの既定より上げたいときは、frontmatterに `priority` を数字で書きます（小さいほど上）。

`thumbnail` を書かなかったブログ記事は、タイトルとカテゴリからサムネイルを作ります。
一覧のカードとSNSでシェアされたときのOGP画像は、どちらもこの画像になります。

## アバター入りのサムネイルを作る

キャラクターと写真を並べたサムネイルは、`pnpm dev` を動かした状態で
[/thumbnail-studio](http://localhost:3000/thumbnail-studio) を開いて作ります。

画面の下で、文字・写真・ポーズをその場で直せます。
記事の名前を入れて「書き出す」を押すと、`public/blog/<記事の名前>/thumbnail.webp` ができます。
できた画像は、記事の `thumbnail` に `<記事の名前>/thumbnail.webp` と書くと使われます。

- **文字** … ラベル・題名・説明を打ち替えます。題名は改行するとそのまま2行になります
- **写真** … プレビューでつまんで動かせます。大きさ・傾きは数値で、重なりは「手前に出す」で決めます
- **アバター** … モーションを選び、スライダーで動きのどこを切り取るか決めます
- **骨を直す** … 骨を選ぶと輪が出ます。輪をドラッグすると、その骨だけ回せます

同じ指定なら何度書き出しても同じ絵になります。動きは時刻で止めていて、
待ち時間に頼っていないためです。

ターミナルからも書き出せます。指定はスタジオと同じで、画面の下に出るコマンドをそのまま使えます。

```bash
pnpm thumbnail --slug <記事の名前> --title "1行目|2行目" --label 生活 --time 2.45
```

| 指定 | 中身 |
| --- | --- |
| `--title` | 大きく出す題名。`\|` で改行する |
| `--subtitle` | 題名の下に添える一行 |
| `--label` | 左上の丸いラベル |
| `--photo` | 右に貼る写真。`public` からのパス |
| `--motion` | アバターのモーション |
| `--time` | モーションを止める時刻（秒） |

演奏などYouTubeに置いた制作物は、`videoUrl` にURLを書きます。上部の大きな画像の代わりに
プレイヤーが主役になり、サムネイルもYouTubeのものを使います。
